# MML の文法

MML を書く人向けの文法の文書。製品仕様は `docs/spec.md` §4。ここに書いた文法を解析するのは `packages/sequencer` の `parseMml`。例は試聴曲 `demo/songs/m3-demo.mml` から引いている。

## 全体

- 1 行が 1 トラックへの記述。行頭のトラック名、空白（1 文字以上）、命令の順に書く。
- 同じトラック名の行は、上から順に連結して解釈する。行の区切りは、命令と命令の間の空白と同じに扱う。そのため、タイ `&` や繰り返し `[ ]` は、同じトラックの次の行へまたいで書ける。
- `;` から行末まではコメント。空行と、コメントだけの行は無視する。
- 大文字・小文字は区別する。命令は小文字で、`B`、`L`、`E` だけが大文字。トラック名は大文字。
- 命令と命令の間の空白は無視する。1 つの命令の中には空白を入れられない（`c 4` は「`c` と、続く `4`」になり、エラー）。
- 時間分解能は四分音符 = 96 ティック。

## トラック名

| 名前 | 用途 |
|---|---|
| `A`〜`P` | メロディ用 |
| `A1`、`A2`、…（`A`〜`P` に 1 以上の整数） | サブトラック。和音を分けて書くのに使う。M3 では、ほかのメロディ用トラックと同じに扱う |
| `R` | ドラム専用 |

- これ以外の名前（`Q`、`a`、`A0` など）はエラー。
- 1 つのトラックは、同時に 1 音だけを鳴らす。和音はサブトラックに分けて書く。前の音の余韻（キーオフ後のリリース）と次の音は重なってよい。

曲の例（`m3-demo.mml` の末尾）：

```
C1 @88 v8 p40 o4 a1 b1 [g1 a1 a1 b1]2 a1 a1 a1 b1
C2 @88 v8 p64 o4 f1 g1 [e1 e1 f1 g1]2 e1 f1 f1 g1
C3 @88 v8 p88 o4 c1 d1 [c1 c1 c1 d1]2 c1 c1 d1 d1
```

## 命令

| 命令 | 範囲・既定 | 内容 |
|---|---|---|
| `c d e f g a b` | — | 音符。直後に `+` または `-`（1 個）、音長、付点の順に書ける。`o4` の `c` が MIDI のノート番号 60。ノート番号が 0〜127 を外れたらエラー |
| `r` | — | 休符。音長と付点を書ける |
| 音長 | 1, 2, 4, 8, 16, 32、3 連の 3, 6, 12, 24, 48 | これ以外の数はエラー |
| `%N` | N は 1 以上の整数 | 音長をティックで直接書く。音符・休符の音長の位置に書く（`c%36`、`r%12`） |
| `.` | — | 付点。重ねてよい（`c4..` は 96 + 48 + 24 ティック）。ティックが整数にならなければエラー |
| `oN` | 0〜8、既定 4 | オクターブ |
| `<` `>` | — | 1 オクターブ下げる・上げる。0〜8 を外れたらエラー |
| `lN` | 音長と同じ数、既定 `l4` | 既定の音長。付点も書ける（`l8.`） |
| `&` | — | タイ。下の「タイ」を参照 |
| `tN` | 1〜999、小数可、既定 120 | テンポ。下の「テンポ」を参照 |
| `@N` | 0〜127、既定 0 | 音色番号。メロディ用トラックだけ。登録されていない番号はエラーにならず、鳴らすときに音源が警告を出す |
| `vN` | 0〜15、既定 12 | 音量。1 段 3 dB で、`v15` が 0 dB、`v0` が無音。持続中のノートにもその位置から効く |
| `pN` | 0〜127、既定 64 | パン（64 が中央）。次の音から効く |
| `qN` | 1〜8、既定 8 | ゲートタイム。下の「ゲートタイム `q`」を参照 |
| `B±N` | −1200〜+1200（セント）、既定 0 | ピッチベンド。符号は省けない（`B50` はエラー）。下の「ピッチベンド `B`」を参照 |
| `[ ... ]N` | N は 1〜255 の整数 | 繰り返し。入れ子にできる。**N は省けない**（`[cdef]` はエラー） |
| `L` | — | ループの開始位置 |
| `E` | — | ループの終了位置 |

- 数を取る命令（`o l t @ v p q` と `[ ]` の回数）で数がないものはエラー。範囲外の値もエラー。

## ドラムトラック（R）

- 音符の代わりにドラム名（`bd sd ch oh cy lt ht cp`）を書く。音長・付点・`%N` は音符と同じ。
- ドラム名を 1 文字の命令より優先して照合する（`lt` はロータムとして読む）。
- 使える命令：`r`、`l`、`%`、`.`、`v`、`p`、`q`、`t`、`[ ]`、`L`、`E`。
- 使えない命令（エラー）：音符、`o`、`<`、`>`、`@`、`&`、`B`。ドラムは高さを持たず、鳴り始めたら鳴り終わるまで鳴るため。`q` は書けるが効き目はない。
- `R` の `v` は、次のドラムから効く。

```
R v12 p64 l8 [bd ch sd ch]4
R [[bd ch sd ch bd bd sd oh]3 bd cy sd ch lt lt ht cp]3
```

## タイ `&`

- `&` は前の音符と次の音符を 1 つの音としてつなぐ。鳴らし直さず、長さを足す。
- `&` の前後の音符が違う高さ（ノート番号で比べる）ならエラー（`c4&d4`）。
- `&` と次の音符の間には、`B` と `v` だけを書ける。それ以外の命令を挟むとエラー。
- `&` の後に音符がない（トラックの終わり、休符、`]` など）ときはエラー。行末の後は、同じトラックの次の行に続けて書ける。
- `[ ]` の境をまたぐタイ（`[c4&]2`）はエラー。

`m3-demo.mml` の例。行をまたぐタイ（弱起のノート）：

```
A r2 r4 r8 g8&
A g4 e8 g8 >c4 <b8 a8
```

タイの途中で音量を変える：

```
A >d4&v12d4&v13d4&v14d4 v11
```

## テンポ `t`

- どのトラックに書いてもよく、書いた位置（ティック）から全トラックに効く。慣例として `A` に書く。
- 違うトラックで同じティックに違うテンポを書いたらエラー。
- テンポが途中で変わる曲でも、ティックから時刻への変換はずれを溜めない。

```
A t112 b4 g4 d4 r8 g8&g4
```

## ゲートタイム `q`

- 音符（タイでつないだものは全体）の長さ × N / 8 ティックでキーオフする。小数は切り捨て、最小 1 ティック。
- 休符には関係しない。

`m3-demo.mml` では、ベースを `q6` で短く切っている：

```
B @34 v13 p56 q6 o2 l8
```

### 現在の実装の挙動（設計では未決）

次の 2 点は、設計で決めていない。現在の実装の挙動を書いておく。

- タイでつないだ音の `q`：最後の音符を読んだ時点の `q` を、つないだ音全体の長さに掛ける。例：`c4 q4 &c4` は、全体（192 ティック）に `q4` を掛けた 96 ティックでキーオフする。
- `L` をはさんだタイ（`c L &c`）：エラーにならない。

## ピッチベンド `B`

- `B±N` は、そのトラックの高さを N セントずらした状態にする。値は次に `B` を書くまで持ち越す。`B+0` で戻す。
- 持続中のノートにもその位置から効く。高さはその時点で一度に変わる（滑らかには変わらない）。効く対象は、そのトラックが最後にノートオンしたノート（ノートオフ後のリリース中でも）。次の音は、その時点の値で鳴り始める。
- つないだ音の途中で変えるには、タイの間に書く。
- 高さを滑らかに変えるには、値を少しずつ変えた `B` を、`%N` の短い音でつないで並べる（`c%6&B+10c%6&B+20c%6`）。
- `B` は 1 ティック単位の位置に置ける（`%1` を使えば。テンポ 120 で約 5 ms）。

`m3-demo.mml` の例（+50 から +200 セントまで上げ、`B+0` で戻す）：

```
A d8 g8 b8 >d8&B+50d8&B+100d8&B+150d8&B+200d8 B+0 <
```

## ループ `L` と `E`、曲の終わり

- 曲の長さは、いちばん長いトラックの長さ。短いトラックは、終わってから曲の終わりまで休みになる。
- `L` があれば、ループ終了の位置まで来たら `L` の位置へ戻って繰り返す。冒頭に `L` を書けば、最初から最後までを繰り返す。`L` がなければ、最後まで鳴らしたら止まる。
- ループ終了の位置は、`E` を書けばその位置、書かなければ曲の終わり。
- `L` は曲全体で 1 つまで（どのトラックに書いてもよい）。2 つ以上、`[ ]` の中、繰り返す長さが 0 になる位置はエラー。
- `E` も曲全体で 1 つまで、どのトラックに書いてもよい。2 つ以上、`[ ]` の中、`L` がない曲、`L` より前の位置はエラー。
- ループ回数は MML では指定しない。
- 戻ったときの状態：各トラックの音色・音量・パン・`q`・ピッチベンドと、テンポは、最初に `L` の位置を通ったときと同じにする。

`m3-demo.mml` では、`B` トラックに `L` と `E` を書いている（イントロは 1 回だけ鳴る）：

```
B [f f >f <f]2 [g g >g <g]2
B L [[c c >c <c]2 [a a >a <a]2 [f f >f <f]2 [g g >g <g]2]2
B [a a >a <a]2 [f f >f <f]2 [d d >d <d]2 [g g >g <g]2 E
```

### ループ位置をまたぐノートの書き方

- `L` より前にノートオンし、`L` の位置で持続中のノートは、戻ったときに鳴らし直さない。
- ループ位置をまたいでノートを鳴らしたいとき（弱起など）は、ループ終了の前にノートオンし、音長をループ終了より後まで書く。そのノートは戻った後も、書いた長さ（`q` を掛けたもの）が尽きるまで持続し、そこでノートオフする。
- `E` より後に書けるのは、ループ終了を越えるノートの残りの長さと、休符だけ。`E` の位置かそれより後でノートオンするノートや、`E` より後の命令（タイの間の `B`・`v` を含む）はエラー。その部分は鳴ることがないため。
- 戻った後、そのトラックの `L` の後のノートが、越えてきたノートと重なってもよい。`B`・`v` が効く対象は、最後にノートオンしたノート。
- `E` がない曲では、曲の終わりより後まで書かれたノートはない。曲の終わりの時点で鳴っている音（最後の音符の余韻など）は切らない。

`m3-demo.mml` の `A` トラックの最後の `g8&g4` は `E`（15 小節目の頭）を越えて書いてあり、ループ後も 3 小節目の 1 拍目まで持続する。

## エラー

- 解析エラーは、行番号・列番号（どちらも 1 から。列は文字単位）・理由（日本語）で返す。行・列は元のテキストの位置で示す。
- 見つけたエラーはまとめて返す（最初の 1 つで止めない）。
- エラーが 1 つでもあれば、再生器は再生しない。試聴ページでは `行 1・列 6：タイの前後でノート番号が違います（60 と 62）` のように一覧で出る。エラーのあったトラックだけを無音にして鳴らす動きは M4。
