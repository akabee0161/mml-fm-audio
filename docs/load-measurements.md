# 負荷の実測記録

試聴ページの「負荷を表示」で測った、AudioWorklet の `process` 1 回（1 ブロック 128 サンプル）の処理時間の記録。合格の線は設けず、数字を記録するだけにする。同時発音数の見直し（`docs/spec.md` §9 の未決事項 4）の材料にする。後のマイルストーンで測り直したら行を足す。

- 平均・最大：`process` 1 回の処理時間（ms）。時計が `Date.now` のときは 1 ms 刻みのため、最大は出さない（−）。
- 割合：1 ブロックの長さに対する平均の割合。音を作るスレッド 1 本の時間のうち何割を使ったかで、CPU 全体に対する割合ではない。100 % を超えると処理が間に合わず、音が途切れる。
- ボイス数：その 1 秒間に鳴っていたボイス数の最大。
